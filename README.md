# get_map_texture

地図タイルを範囲指定でダウンロードし、1枚の画像に合成するツール。  
CLI / GUI / Chrome 拡張の 3 形態で利用可能。

## 対応ソース

| ソース | 最大ズーム | 備考 |
|---|---|---|
| **Mapbox 衛星画像** | 22 | ✅ 商用利用可・無料枠あり（要トークン） |
| ESRI 衛星画像 | 19 | 高解像度・グローバル |
| Google 衛星画像 ⚠️ | 21 | 最高解像度（利用規約に注意） |
| 地理院タイル 空中写真 | 18 | ✅ 日本国内・商用利用可 |
| 地理院タイル 標準地図 | 18 | ✅ 日本国内・商用利用可 |
| 地理院タイル 淡色地図 / 白地図 / 色別標高図 | 14〜18 | ✅ 日本国内・商用利用可 |

## Chrome 拡張（おすすめ）

Google Maps 上で直接範囲を選択してタイル画像をダウンロードできる。

### インストール

1. [Releases ページ](https://github.com/omwegg/get_map_texture/releases/latest) から `tile-downloader-chrome-v2.0.0.zip` をダウンロード
2. ZIP を解凍する
3. Chrome で `chrome://extensions` を開く
4. 右上の「**デベロッパー モード**」を **ON** にする
5. 「**パッケージ化されていない拡張機能を読み込む**」をクリック → 解凍したフォルダを選択
6. 拡張機能一覧に「地図タイル取得ツール」が追加される

### 使い方

1. [Google Maps](https://www.google.com/maps) を開く
2. 右下に表示される 🗺️ ボタンをクリック → パネルが開く
3. **画像ソース**を選択（ESRI 衛星画像・Google 衛星画像・地理院タイルなど）
4. **ズームレベル**を選択（数値が大きいほど高解像度）
5. 「**📍 範囲を選択**」をクリック
6. 地図上で**左上**にしたい場所をクリック → マーカー ① が表示される
7. 地図上で**右下**にしたい場所をクリック → マーカー ② と矩形が表示される
8. パネルにタイル枚数が表示される（100枚超の場合は確認ダイアログが出る）
9. 「**ダウンロード**」をクリック → 進捗バーが進み、完了すると JPEG が保存される

> **Tips**
> - 選択中に**右クリック**するとキャンセルできる
> - パネルはヘッダーをドラッグして移動できる
> - 左上/右下を逆にクリックしても自動補正される
> - 「ビューポート情報を取得できません」と出たら、地図を少しドラッグして URL を更新してください

## GUI

デスクトップ GUI。Google Maps からコピーした座標を貼り付けて使う。

### セットアップ

```bash
pip install pillow
```

### 使い方

```bash
python get_map_texture_gui.py
```

1. **タイルの種類**を選択（空中写真・標準地図など）
2. **ズームレベル**を選択
3. Google Maps で左上にしたい場所を**右クリック** → 表示された座標をクリックしてコピー
4. 「**左上**」欄に貼り付け（例: `35.6812, 139.7671`）
5. 同様に右下の座標をコピーして「**右下**」欄に貼り付け
6. タイル枚数が自動計算されて表示される
7. 「**ダウンロード開始**」をクリック
8. 完了するとプレビューが表示され、`export/` フォルダに JPEG が保存される

## CLI

ターミナルでの対話形式。

### セットアップ

```bash
pip install pillow
```

### 使い方

```bash
python get_map_texture.py
```

プロンプトに従って入力：

1. タイルの種類を番号で選択
2. 左上のタイル X 座標・Y 座標を入力
3. 横方向・縦方向のタイル数を入力
4. ズームレベルを入力

`export/` フォルダに合成画像が出力される。

> タイル座標は [地理院タイル座標確認ページ](https://maps.gsi.go.jp/development/tileCoordCheck.html) で確認できる。

## タイルの仕組み

- タイルは 256×256 px の画像データ
- ズームレベル 0 が世界全体、1 上がるごとに解像度が縦横 2 倍
- ズームレベル 18 でタイル1辺 ≈ 約125m（北緯35度）
- PLATEAU の 3 次メッシュは地理院タイルのズームレベル 15 に対応

## 利用規約・商用利用について

> **重要**: 各タイルソースにはそれぞれ固有の利用規約があります。  
> 取得した画像を利用する前に、必ず該当する規約を確認してください。

### 地理院タイル — ✅ 商用利用可

- **ライセンス**: [政府標準利用規約（第2.0版）](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)
- **商用利用**: **可能**（出典の記載が必要）
- **出典表記**: `出典：国土地理院ウェブサイト（https://maps.gsi.go.jp/）`
- **APIキー**: 不要
- **一括ダウンロード**: 常識的な範囲で可能

### Mapbox 衛星画像 — ✅ 商用利用可（おすすめ）

- **ライセンス**: [Mapbox Terms of Service](https://www.mapbox.com/legal/tos)
- **商用利用**: **可能**
- **無料枠**: 月 **750,000 リクエスト**（Raster Tiles API）
- **超過料金**: $0.25 / 1,000リクエスト
- **APIキー**: 必要（[無料アカウント](https://account.mapbox.com/)で取得可）
- **利用手順**: アカウント作成 → アクセストークンを Chrome 拡張のパネルに貼り付け

### ESRI World Imagery — ⚠️ 条件付き（注意が必要）

- **ライセンス**: [Esri Master License Agreement](https://www.esri.com/en-us/legal/terms/full-master-agreement)
- **商用利用**: **デフォルトでは非商用のみ**（商用利用には Esri との別途有償ライセンス契約が必要）
- **一括ダウンロード**: **明示的に禁止**（規約違反 = material breach）
- **注意**: 本ツールでの利用方法（タイルの一括取得・結合）は規約上グレーゾーンです

### Google 衛星画像 — ❌ 利用規約上の制約あり

- **ライセンス**: [Google Maps Platform 利用規約](https://cloud.google.com/maps-platform/terms)
- **商用利用**: 正規 API（Maps Platform）の利用が必要（APIキー・課金設定が必須）
- **直接タイル取得**: **規約で禁止**（pre-fetching・キャッシュ・スクレイピングすべて不可）
- **注意**: 本ツールでの利用方法は Google の利用規約に抵触する可能性があります
